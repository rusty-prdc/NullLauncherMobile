nullLauncher Mobile

Политика конфиденциальности

Действует с 18 октября 2026 года · приложение nullLauncher Mobile (далее — «Приложение»)

1. Какие данные обрабатываются

Приложение обрабатывает только те данные, которые необходимы для его работы:

  • Данные учётной записи Microsoft / Xbox — токены доступа и идентификатор профиля. Используются исключительно для официального входа в игру методом device-code: пароль пользователя в Приложение никогда не передаётся и не хранится.
  • Технические данные о вылетах — модель устройства, версия О Android и стек ошибки. Записываются локально в файлы журнала для диагностики сбоев и не отправляются третьим лицам.
  • Данные о подписке — статус и срок действия Premium. Оплата выполняется через RuStore Pay; платёжные данные Приложению недоступны.

2. Какие данные НЕ собираются

  • Пароли от учётных записей.
  • Геоданные, контакты, файлы пользователя (миры и сборки остаются на устройстве).
  • Данные для рекламы и аналитики: в Приложении нет рекламных и аналитических SDK, трекеров и профилирования.
  • Передача данных сторонним рекламным сетям.

3. Цели обработки

  • Авторизация в игре (вход через Microsoft).
  • Диагностика ошибок запуска и улучшение стабильности.
  • Обеспечение работы купленной подписки Premium.

Правовое основание — исполнение договора с пользователем (ст. 6 ч. 1 п. 3 ФЗ № 152-ФЗ «О персональных данных»).

4. Хранение и защита

Все данные хранятся локально на устройстве пользователя и не передаются на серверы Разработчика. Токены хранятся в защищённом хранилище приложения. Приложение не содержит вредоносного кода и не выполняет скрытых сетевых действий.

5. Сторонние сервисы

  • Microsoft / Xbox — авторизация (политика: microsoft.com/privacy).
  • Mojang / Xbox Live services — данные профиля игры для входа.
  • RuStore Pay — обработка платежей подписки (политика: rustore.ru).
  • Modrinth — открытый каталог модов: запросы отправляются только при поиске/установке по действию пользователя.

Приложение не передаёт персональные данные сторонним сервисам сверх необходимого для их прямого назначения.

6. Как удалить данные

  • В Приложении: Профиль → Выйти из аккаунта — удаляет токены и профиль Microsoft с устройства.
  • Полное удаление: Настройки Android → Приложения → nullLauncher Mobile → Удалить данные — стирает все локальные файлы, включая журналы и сборки.
  • Запрос по почте/Telegram разработчику: @rustywvv.

7. Дети

Приложение не предназначено для сбора данных детей. Используется официальная авторизация Microsoft, где возрастной учёт задаётся родителем на стороне Microsoft.

8. Изменения политики

При обновлении политики новая редакция публикуется на этой странице с указанием даты. Продолжение использования после обновления означает согласие с новой редакцией.
