О лаунчере

nullLauncher Mobile — бесплатный лаунчер Minecraft Java для Android

nullLauncher Mobile — это Android-лаунчер, созданный для запуска Minecraft Java Edition на смартфонах. Устанавливай игровые версии, собирай собственные модпаки, управляй модами и настраивай игру под себя в одном приложении.

  • Менеджер версий и загрузчики

    Выбирай версии Minecraft и устанавливай поддерживаемые загрузчики модов: Fabric, Forge, NeoForge и другие.

  • Моды и модпаки

    Находи моды, собирай собственные сборки и управляй установленными дополнениями. Интеграция с каталогом Modrinth планируется.

  • Настройки производительности

    Выделение оперативной памяти, параметры игры и другие доступные настройки — под твоё устройство.

  • Управление мирами

    Храни миры, создавай резервные копии и переноси сохранения между поддерживаемыми сборками.

  • Современный интерфейс

    Тёмное оформление, фиолетовые акценты и навигация, сделанная под мобильные устройства.

Вопросы

Частые вопросы

Что такое nullLauncher Mobile?

Android-лаунчер для запуска Minecraft Java Edition на смартфонах с помощью совместимого игрового окружения. Он объединяет установку игры, управление сборками, модами и настройками в одном приложении.

Нужна ли лицензия Minecraft Java Edition?

Да, для игры могут потребоваться лицензия Minecraft Java Edition и совместимое устройство. nullLauncher Mobile — сторонний проект, не связанный с Mojang Studios или Microsoft.

Какие загрузчики модов поддерживаются?

Лаунчер устанавливает поддерживаемые загрузчики модов: Fabric, Forge, NeoForge и другие. Находи моды, собирай собственные сборки; интеграция с каталогом Modrinth планируется.

Бесплатен ли nullLauncher Mobile?

Да. Проект развивается вместе с XPRODC, распространяется бесплатно и имеет открытый исходный код на GitHub.

Все ли функции уже работают?

Нет. Описанные возможности, которые ещё не реализованы, не следует считать доступными в текущей версии. Доступность функций зависит от версии Android и игровой среды; статус разработки смотри в репозитории на GitHub.

Как узнать о новых функциях?

Следи за обновлениями в репозитории NullLauncherMobile на GitHub: релизы и изменения публикуются там.
